# Repository context

## Custom MCP services

Use the service map in [MCP_SERVERS.md](MCP_SERVERS.md) when working with the self-hosted apps in this repository. It lists all 14 MCP integrations, their capabilities, endpoints, and encrypted credential sources. Prefer the relevant connected MCP tools for service operations and use repository manifests for deployment configuration.

Do not put decrypted credentials into tracked files, tool output, commits, or documentation. Existing user instructions about Git attribution continue to apply.
